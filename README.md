 📝 Descripción
Este proyecto consiste en un sistema de gestión hotelera desarrollado en Python, cuyo objetivo es administrar las operaciones básicas de un hotel mediante el uso de archivos de texto.

El sistema permite:

Registrar huéspedes.
Registrar reservas.
Consultar las habitaciones disponibles y su estado.
Realizar el check-in, actualizando el estado de la habitación y de la reserva.
Realizar el check-out, liberando la habitación y finalizando la reserva.

La información se almacena en archivos de texto (huespedes.txt, habitaciones.txt y reservas.txt), lo que permite conservar los datos entre ejecuciones del programa.

Cómo ejecutar el proyecto:

1.Descargar o clonar este repositorio.
2.Verificar que Python 3 esté instalado en el equipo.
3.Abrir una terminal en la carpeta del proyecto.
4.Ejecutar el archivo principal con el siguiente comando:
```bash
python 1hotel.py
```

El programa se ejecutará en la consola y mostrará el menú principal desde donde se podrán realizar todas las operaciones.

Archivos utilizados

El sistema utiliza los siguientes archivos para almacenar la información:

huespedes.txt
habitaciones.txt
reservas.txt

Estos archivos deben encontrarse en la misma carpeta que el programa.
